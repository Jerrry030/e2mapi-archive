# 简驭 E2M API

E2M API 是面向 AI 网关生态的托管运维与调度平台，目标是让 sub2api、New API、CPA/CLIProxyAPI 等网关实例易于部署、易于管理、易于恢复。

## 定位

简驭不是新的单一 API 网关，而是统一控制面：

- 集成运维托管
- 服务部署与升级
- 号池自助管理
- 上游健康检测与自动切换
- Runbook 自动处置与审计
- QQ 群答疑和运维协同
